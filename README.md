# AmerIsmailAI — Predictive Maintenance for Industrial Systems

Applying machine learning to industrial sensor data for predictive
maintenance and anomaly detection, inspired by real SCADA and industrial
monitoring environments in power generation.

> **Data note:** all data in this repo is **synthetic**, generated by
> `src/generate_synthetic_data.py`. No real plant or customer data is used.
> The simulated sensors (vibration, temperature, pressure, current) follow
> realistic patterns: per-machine baselines, slow drift, load changes,
> random spikes, and a degradation phase that ends in a failure.

## What it does

- **Failure prediction** — a RandomForest classifier predicts whether a
  machine will fail within the next 48 hours, from rolling 24-hour sensor
  statistics, normalised per machine.
- **Anomaly detection** — an IsolationForest flags unusual operating points
  without needing any labels.

## Honest results (synthetic data)

Evaluated on machines the model never saw during training (group split),
because a random row split would leak between neighbouring hours:

- Accuracy 0.86, ROC AUC 0.95
- Failure recall 0.75 at precision 0.81

These are demo numbers on simulated data, not a claim about real equipment.

## Run it

```bash
pip install -r requirements.txt
python src/generate_synthetic_data.py   # writes synthetic_sensor_data.csv
python src/predictive_maintenance.py    # prints metrics, saves 2 plots
```
